# ClipForge — GitHub Pages website

A responsive static landing page for an AI video-clipping startup concept.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `clipforge-website`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL appears in Settings → Pages.

## Included
- Responsive dark landing page
- Features, workflow, pricing, FAQ, and contact sections
- Mobile navigation and monthly/yearly pricing toggle
- Local file selection demo (no upload, AI processing, or payment)
- Basic metadata and accessible interaction states

## Before a real launch
- Verify trademark, domain, and social-handle availability for ClipForge.
- Replace `hello@clipforge.ai` with an email address you control.
- Connect a real backend for authentication, file upload, video processing, and AI features.
- Connect a payment provider and implement subscription lifecycle handling before charging customers.
- Add real privacy policy, terms, cancellation/refund terms, and cookie disclosures as applicable.
- Ensure uploaded clips use content you own or have permission to republish.
- Review all pricing against processing, storage, transcription, and support costs.
